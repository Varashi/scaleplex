## CRITICAL

### 1. Multi-region top/middle overlays render blank
`worker/agent/region.go:189-234` + `subprerender.go`

`planMultiRegion` sets per-region `BandY` for overlay placement but carries no crop-Y. `buildSubPrerenderArgs` unconditionally crops the **bottom** band (`crop=W:BandHeight:0:Height-BandHeight`). Top/middle regions render text at y≈0 / center but crop slices the bottom → transparent band. Net: **the active feature (multi-region pre-render) silently produces blank overlays for every non-bottom cue.** No error, just missing subtitles.

**Fix:** Add `CropY` to `RegionPrerenderSpec`, set per anchor in `planMultiRegion` (bottom: `Height-BandHeight`; middle: centered; top: 0), crop at that offset, plumb through `spawnMultiRegion`. Verify against latest commit — mid-feature here.

### 2. Matroska EBML unbounded/unknown-size not rejected
`worker/agent/matroska.go:155,188,206`

`readEBMLSize` doesn't reject the all-ones "unknown size" reserved value (~2^56), and `int(szValue)` conversions aren't bounds-checked in uint64 domain. On 32-bit, `start+int(szValue)` overflows negative, bypasses `> len()` guards → OOB panic on malformed MKV. Latent hole on 64-bit. Untrusted-input parser = highest risk.

**Fix:** Reject unknown-size pattern in `readEBMLSize` (value == `(1<<(7*width))-1` → ok=false); compare `szValue > uint64(len(remaining))` before the `int` cast.

### 3. Registry replacement race orphans live session
`orchestrator main.go:106-110, 537` *(worker registry)*

Two `/task` for same `session_id`: `register()` overwrites map; old handler's `defer unregister(id)` deletes unconditionally → removes the **new** task's entry. New ffmpeg keeps running but kill returns 404, capacity accounting drifts, checkpoint/recovery breaks.

**Fix:** Make unregister identity-checked: `unregister(id, t)` doing `if r.tasks[id]==t { delete(...) }`; pass task pointer from defer.

### 4. Orchestrator `/task` unauthenticated → arbitrary ffmpeg exec
`orchestrator/main.go:280-281,371`

Any POST `/task` forwards `args`/`env`/`cwd` verbatim to a worker that spawns the process. Any compromised pod / SSRF source runs arbitrary ffmpeg (`-f lavfi`, file read/write filters, arbitrary `-i`/output paths) on GPU worker NFS mounts. No shared-secret/mTLS anywhere.

**Fix:** Shared-secret header (constant-time compare) or mTLS shim→orch→worker; NetworkPolicy on the Service. At minimum gate `/task` and `/task/<id>/kill`.

### 5. Shim ships full PMS environment in cleartext
`shim/cmd/shim/main.go:321-349`

`collectEnv` copies **all** of `os.Environ()` — incl. `X_PLEX_TOKEN`, claim tokens, injected secrets — over plaintext HTTP to orchestrator and every worker. Combined with #4, any `/task` reader or on-path observer harvests Plex tokens.

**Fix:** Allowlist only needed vars (`LIBVA_*`, `FONTCONFIG_*`, `SCALEPLEX_*`, specific paths); TLS the hop.

### 6. Orchestrator unbounded body + no server timeouts
`orchestrator/main.go:285,376` (+ `relay/main.go:176`)

`io.ReadAll(r.Body)` with no `MaxBytesReader` → OOM via one POST. `http.Server` sets no `ReadHeaderTimeout` → slowloris pins goroutines.

**Fix:** `http.MaxBytesReader`; set `ReadHeaderTimeout` (~10s) on both servers (leave WriteTimeout off for streaming path).

## HIGH

### Worker rewriter
- **Slice-bounds panics on trailing flags** — `rewriter.go:2069` (`-map`), `:1949` (`-init_hw_device`), `:2105/2110/2116` (`-codec:0`). Unguarded `args[idx+1]` after only `idx>=0` check; malformed argv ending in a bare flag panics the agent. → add `idx+1 < len(args)` guards (pattern already used elsewhere in file).
- **Count-vs-filter anchor mismatch (SRT)** — `region.go:126-128` uses *last* `{\anN}`, `region.go:358-364` (`classifyCueAnchor`) uses *first*. Multi-line cue counted into one region, written to another → empty filtered file or wrong band size. → shared first-match helper for both.

### Worker subtitle / runtime
- **Region pre-render processes leak on mid-loop spawn failure** — `subprerender.go:464-467`. `spawnMultiRegion` returns error after starting regions 0..i-1; caller only runs `cleanup()` (FIFOs), never kills started cmds. Daemon → leaked ffmpeg per failure → fd/process exhaustion. → kill+Wait all started cmds on error path / fold into `cleanup()`.
- **Watcher-setup vs first-segment race** — `segwatch.go:97-149,166-208`. ffmpeg started before `watcher.Add`; fast first segment missed → `segment-ready` never fires, `lastSeq` under-reported (resume restarts too far back). Defeats the latency feature it exists for. → initial `os.ReadDir` scan after `Add` to catch pre-existing files.
- **fd leak on pipe-creation failure** — `main.go:495-504`. If `StderrPipe`/`StdoutPipe` fail after progress pipe created, returns without closing `progressReader/Writer` (2 fds/occurrence). → close on those error branches.
- **Unawaited prelude goroutine** — `main.go:626-629`. Fire-and-forget, unsynchronized with teardown, no concurrency bound. (lower confidence) → join via WaitGroup.

### Orchestrator / shim
- **`injectResumeFlags` slice-aliasing** — `checkpoint.go:252-309`. `append(out[:iIdx], ...)` with both `-ss` and `-copyts` inserts can clobber the live tail via shared capacity. → use three-index `out[:i:i]` to force copy, or splice into fresh slice.
- **Recovery poller/session-tracking scope** — `main.go:426-427` (poller bound to first worker, not updated on swap) + `:559-560` (deferred `sessions.del` fires on first upstream return mid-recovery → kill 404s the still-active worker). → manage poller + session map at outer `proxyToWorker` scope, update URL on swap.
- **Manifest CSV rewrite swallows body-read error** — `relay/main.go:104-114`. On `ReadAll` error, forwards drained reader → PMS serves broken segments silently. → return 502 on read error.

### C patches (0108/0109 — the two uncommitted patches)
- **Blocking `accept4` in filter-graph activate loop** — 0108 `vsrc_zerocopy_va.c` `activate()`. Listen socket never set non-blocking; `EAGAIN` path is dead → graph thread blocks until peer connects, stalling playback. → `SOCK_NONBLOCK` on listen fd.
- **Surface-lifetime UAF under OOM** — 0109 `filter_frame()`. `av_frame_clone` return unchecked; on NULL the ring slot goes NULL, surface released early, main process may composite freed VRAM. → check clone, free+return ENOMEM.
- **fd leaks on error paths** — 0108 `init()` (listen_fd on bind/listen fail), `recv_hdr_fd()` (partial read EPROTO leaks SCM_RIGHTS fd); 0109 `filter_frame()` (`vaExportSurfaceHandle` multi-object: only `objects[0].fd` closed, no `num_objects==1` check).
- **`rename.sh` unquoted `$files`** — word-splitting/glob on `sed -i '...' $files`. → `find -exec` or `mapfile -d ''`.

## MEDIUM (selected)

- **`escapeFilterPath` misses `,` `[` `]` `;`** — `rewriter.go:555-560`, used at `subprerender.go:114`. Subtitle path with comma (common: `Movie, The (2020).srt`) breaks the burn-in filtergraph; adversarial naming could inject filters. *(flagged by 2 reviewers)* → single-quote the value or escape filtergraph separators.
- **`lowerExt` ignores path separators** — `band.go:39-45`. `LastIndex(p,".")` over whole path misclassifies subtitle files in dotted dirs → wrong/no parser. → `filepath.Ext` on basename.
- **PMU short-read treated as full counter** — `load.go:224-227`. `unix.Read` count ignored → garbage busy counter. → check `n<8`.
- **Process-group not signaled on cancel** — `main.go` (Setpgid set, but `CommandContext` SIGKILLs leader only) → orphaned grandchildren. → `cmd.Cancel` kills `-pgid`.
- **`ensure_connected` busy-spin 10s in filter thread** — 0109. → `FFERROR_NOT_READY` + reschedule.
- **`iterate.sh` `BIN_PATH` interpolated into `bash -c`** — operator-controlled env, but injection-shaped. → pass via `env` var, not string interpolation.
- **Orchestrator copies hop-by-hop headers verbatim** — `main.go:563-565` → framing desync. → strip Connection/Transfer-Encoding/etc (relay already does).
- **`persistArgvOutcome` read-modify-write not atomic vs concurrent capture** — `main.go:899-904`. Bounded by idempotency Stat guard; debug corpus only.
- **Manifest body 4096 LimitReader may truncate throttle substring** — `progress_report.go:381-383`. PMS replies tiny; low likelihood.
